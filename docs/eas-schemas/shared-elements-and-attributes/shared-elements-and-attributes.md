# Shared Elements and Attributes

As part of the alignment across the three EAS standards, many elements and attributes are shared among EAD version 4, EAC-CPF version 3 and EAC-F version 1. Historically, each standard was thought of as a separate entity entirely, and the elements and attributes which make up a particular standard were tailor-made for that standard. From this point in time, the three standards now share many elements and attributes, thus allowing for data reuse and clean mappings between them. The XHTML standard, which was created for display in a web interface, is now being used as an extension point rather than attempting to re-create the XHTML standard in the EAS.

Shared elements and attributes are defined in the Tag Library, which specifies their structure, usage, and definitions.
